# ミエルカ GEO（mieru-ca.com）LP 分析

- 出典: mieru-ca.com のサービス LP（スマホ表示）のキャプチャ 12 枚（2026-09-06 共有）
- 提供元: 株式会社 Faber Company（ミエルカシリーズ）。ミエルカ SEO のブランドで GEO（Generative Engine Optimization）向けの製品
- 位置づけ: AI 検索（AI Overviews、ChatGPT、Gemini など）に特化した分析ツール。LP は 01〜05 の 5 機能で構成
- 画面内の日付は 2026 年（調査日 2026/06/01、2026/07/11 など）、対象モデルに GPT-5.5 / Gemini 3 / Claude Sonnet 4.6 / Google AI モード が登場する

| # | 機能 | 一言 |
|---|---|---|
| 01 | AIO（AI Overviews）レポート | 登録 KW の AIO 出現状況、AIO 内でのサイト引用状況、AIO 内の頻出トピック |
| 02 | AI 検索流入レポート | AI 検索からの流入・CV をチャネル別 / サービス別 / ページ別に可視化 |
| 03 | LLM リサーチ | 1 プロンプトを複数モデルに投げ、言及・引用を ○× 行列で確認（単発調査） |
| 04 | AI 検索シェアモニタリング | プロンプト拡張、ブランドシェアの定点観測、AI クエリファンアウト |
| 05 | サイトレポート | GA4 系 KPI の前期比、流入と検索順位の複合グラフ、自社・競合の最新順位 |

## 01. AIO レポート

「AIO で自社がどのように扱われているか、競合比較で視覚的に把握できます」

### 01-a 登録 KW の AIO 出現状況

- 比較単位: 日 / 週 / 月 の切替（キャプチャは週。x 軸は「4/1-4/7 … 7/30-8/5」）
- フィルタ: KW グループの複数選択「選択中（4）」。選択中グループ名を帯で表示。グループ名は `00_注力KW, 01_指名検索, 02_コンテンツマーケティング, 03_オウンドメディア, 04_SEOツール, 05_Webマーケティング, 06_ソーシャル, 07_アクセス解析, 08_競合, 09_動画, 10_広告, 11_ヒートマップ, 12_コンバージョン` のように番号付き命名
- グラフ: 左軸 = 登録キーワード数（0〜200）、右軸 = 出現率（%）。積み上げ棒 = 出現あり（濃い青）/ 出現なし（薄い青）、折れ線 = 出現率（AIO が表示された KW の割合）
- 読み取れる傾向: 4 月初旬は出現ありが 1 割弱、8 月には約 5 割に増加（AIO の表示範囲拡大を示す）

### 01-b サイトの引用状況

「AI 検索で引用されやすい表現・構成を抽出し、コンテンツ改善に活用できます」

- 同じ 比較単位 / グループフィルタ
- 積み上げ棒の分類（5 区分）: **自社のみ** / **競合のみ** / **自社&競合あり** / **自社&競合なし** / **AIO 表示なし**
- 折れ線: **登録 KW の AIO 引用率**（自社が引用された KW の割合）
- KW × 期間 を 5 区分に分けることで「AIO は出ているが誰も引用されていない（= 取りに行ける）」「競合だけ引用されている（= 負けている）」が一目で分かる

### 01-c AIO 内での出現トピックを把握（KW 単位の詳細画面）

「自社に足りないトピックを補うことで、AIO に引用・表示される可能性を高められます」

- 画面タイトル: 「コンテンツとは」AIO 表示状況
- KPI カード: このクエリでの AIO 表示率（100%）/ 月間検索数（60,500）/ 自社サイトの引用率（100%、前期比 ↑80%）
- 表「AIO に頻出しているトピック」（全 8 件）
  - 列: AIO のトピック / 出現の割合（選択期間内）と前期比 / 出現の傾向（選択期間内、スパークライン）/ 優先度（1〜5 のドット。5 = 赤、4 = ピンク、3 = 黄、2 = 青）
  - 行例: コンテンツの主な特徴と例 22.22%（↑22.22%）優先度 5 / 企業における「コンテンツ」の活用 22.22% 優先度 4 / 「コンテンツ」が使われる背景 22.22% 優先度 4 / 具体的な例 22.22% 優先度 3 / 企業におけるコンテンツの活用例 22.22% 優先度 3 / ポイント 55.56%（↑55.56%）優先度 2
- 解釈: AIO 本文を日次で取得し、含まれる「トピック（見出し相当）」を抽出・正規化して出現割合を集計している。優先度は「よく出る × 自社ページに足りない」で決めていると推定（「ポイント」は最頻出だが優先度 2 = 自社が既に書いているため、と読める）

## 02. AI 検索流入レポート

「ChatGPT・Gemini などサービス別に流入を分析。AI 検索が成果につながっているかどうかがわかります」

### 02-a 流入チャネル別

- 比較単位 日 / 週 / 月、指標切替 ユーザー数 / セッション数
- 左軸 = 流入ユーザー数、右軸 = 比率（0〜1.00）
- 棒: 全てのセッション（灰）/ 自然検索（橙）/ AI 検索（紫）
- 折れ線: **AI 検索率（対総セッション）**（赤）/ **AI 検索率（対自然検索）**（紫）
- AI 検索流入を「総セッション比」と「自然検索比」の 2 つの率で追う設計

### 02-b AI サービスごとの流入を比較

「各 AI サービスのうち、CV しやすいユーザーを分析できます」

- 「流入元サービス別」積み上げ棒（週）。凡例: ChatGPT / Microsoft Copilot / Gemini / Claude / Felo / Perplexity（数値ラベル例: ChatGPT 27、Copilot 13、Gemini 6、Claude 4、Felo 3、Perplexity 1）
- 右上に「流入元追加のお問い合わせ」リンク（対応サービスの追加を受け付ける）
- ユーザー数 / セッション数 切替

### 02-c ページ別の CV 発生状況

「AI 検索流入で CV しやすいページが分かると、改善対象を優先的に決められます」

- 表「ページ別・AI 検索流入状況」: 列 = ランディングページ / 流入元（サービス名バッジ）/ セッション数 / 流入ユーザー数 / キーイベント（ソート可）
- フィルタ: 「キーイベント名から絞り込み」（選択中: 問い合わせ, first_visit, ページ閲覧, スクロール …）
- 表示件数 10、1-10 of 64、ページネーション
- 行例: /blog/owned-media-financial/ Felo 22,484 / 1,845 / 0、/blog/seo-measures/ ChatGPT 10,692 / 2,904 / 2、同ページ Gemini 2,758 / 556 / 3、/blog/use-ai-genspark/ Claude 1,183 / 465 / 4
- 同一ページが流入元ごとに別行になる（ページ × サービス の粒度）

## 03. LLM リサーチ（単発調査）

「自社と競合が AI サービス上でいつ・どのように・どれくらい言及・引用されているかを確認できます」

- 調査 1 件の画面「20260601 LLM リサーチ」（日付プレフィックス付きの名前）
  - 調査プロンプト: 銀行・クレジットカード連携できて、家族共有できる家計簿アプリは？
  - 調査対象サイト: mieru-ca.com, penguin-seo.com, nekonote.com
  - 調査対象テキスト: ミエルカ, ミエルカSEO, ペンギンSEO, ネコのアナリティクス
  - 「Excel でダウンロード」
- 表 1「調査テキスト言及状況」: 行 = 調査対象テキスト、列 = **GPT-5.5 Thinking / GPT-5.5 Instant / Gemini 3 Thinking / Gemini 3 Fast / Google AI モード / Claude Sonnet 4.6**、値 = ○ / ×
- 表 2「サイト引用状況」: 行 = 調査対象サイト、列 = 同上、値 = ○ / ×
- 特徴: 同じベンダーでも「推論モデル / 高速モデル」を別列にしている（結果が異なるため）。Google AI モード（AI Mode）を対象に含めている。ブランド（テキスト）とサイト（ドメイン）を分けて判定する点は User Insight と同じ

## 04. AI 検索シェアモニタリング（定点調査）

### 04-a プロンプト拡張

「入力した参考プロンプトをもとに、関連プロンプトをまとめて生成できます」

- 結果画面: 元プロンプト「SEO 対策とは何かを初心者向けにわかりやすく教えて」、調査対象 https://marketing-tech-review.jp、作成日 2026/06/01、作成プロンプト数 50
- 「拡張結果: 入力したプロンプトをもとに生成されたプロンプトを、一覧で確認・コピーできます」。ボタン: プロンプトのみコピー / カテゴリ名を入れてコピー
- カテゴリごとにアコーディオン。例「課題解決 計 19 個 — 困りごとや問題を解決する相手・方法を探しているプロンプト」（カテゴリの一文定義付き、カテゴリ単位のコピー）
- 生成例（右端に文字数）: SEO 対策をしているのに検索順位が上がらない原因と改善方法を教えて（33 文字）/ SEO 初心者が何から始めればいいかわからないときの進め方を教えて（32）/ 記事を書いてもアクセスが増えない場合の SEO 改善ポイントを教えて（32）/ SEO 対策に時間をかけても成果が出ないときの見直し方を教えて（30）/ キーワード選定がうまくできないときの具体的なやり方を教えて（30）/ 検索意図がつかめず記事の方向性に迷うときの考え方を教えて（28）/ コンテンツを書いても上位表示されない原因と対策を教えて（27）
- 役割: モニタリング用プロンプト集合を人手で考える負担（User Insight では「導入後案内」で人がサポートしている部分）を自動化

### 04-b AI 検索シェアモニタリング（ブランドシェア）

「複数プロンプトを登録し、各 AI モデルにおける自社と競合の露出度合いなどを定点観測。ブランドシェアスコアなどのグラフで露出度合いの遷移が把握できます」

- グラフ「ブランドシェア」: 縦軸 = ブランドシェア率（0〜100%）、横軸 = 日（4/3〜4/10）。「プラットフォームで絞り込み」プルダウン
- 系列 = ブランド（自社 + 競合）: ミエルカSEO / サーチスコープ / キーワードナビ / ランクレーダー / サイトインサイト。凡例はチェックボックスで表示切替
- ツールチップ（2026 年 4 月 5 日）: ミエルカSEO 27% / サーチスコープ 69% / キーワードナビ 32% / ランクレーダー 12% / サイトインサイト 41%。合計が 100% にならないので「各ブランドの言及率」（プロンプトのうち言及された割合）と推定

### 04-c AI クエリファンアウト

「入力した各プロンプトからファンアウトクエリを抽出することで、プロンプトのブランド露出や検索意図の網羅性を検証できます」

- 画面: 「SEO 対策とは何かを初心者向けにわかりやすく教えて 他 2 件」、調査対象プラットフォーム ChatGPT / Gemini、調査日 2026/07/11、ユーザー 佐藤 美咲
- 右上リンク「クエリをサジェストインテンションで分析する」（同社の別機能への導線）
- 検索「調査プロンプトで検索」、プラットフォーム絞り込み「すべて」
- 表: プロンプト / プラットフォーム / クエリ / 最新情報（✓ フラグ）
  - クエリ例: SEO ツール おすすめ / SEO ツール 比較 / SEO ツール ランキング / SEO ツール 選び方 / SEO ツール 機能一覧 / SEO ツール キーワード調査 比較 / SEO ツール 被リンク分析 比較 / SEO ツール 順位チェック ツール 比較 / SEO ランキング要因（最新情報 ✓）/ SEO ランキング要因 最新
- 解釈: AI が 1 つのプロンプトに答えるために内部で発行した検索クエリ（クエリファンアウト）を取得して一覧化。これで「AI がそのプロンプトでどんな検索意図を調べているか」と「自社がそのクエリで上位にいるか（網羅性）」を検証できる。「最新情報」は最新性を求めるクエリ（"最新" を含むなど）のフラグ

## 05. サイトレポート

「AI 検索経由で流入したユーザーの動きや検索順位の変化をまとめて可視化」

### 05-a サイト状況サマリー

「流入ページ・CV・行動データを一覧化。特に CVR の高いページや、改善が必要な箇所を自動で発見します」

- 「ページ一覧」KPI（期間合計と前期間比）: ユーザー数 ↑63,941（前期 58,815、+8.7%）/ 新しいユーザー ↑39,792（39,055、+1.9%）/ 平均エンゲージメント時間 ↑8,650 秒（7,404 秒、+16.8%）/ エンゲージメント率 ↓60.29%（60.76%、-0.8%）/ 自然検索セッション ↑42,208（35,822、+17.8%）/ コンバージョン ↑303（271、+11.8%）
- グラフ「流入と検索順位」: チャネル別の積み上げ棒（自然検索 / ノーリファラー / 参照サイト / 動画サイト / メール / 有料広告）+ 折れ線 **登録キーワードの平均順位**（赤、右軸は順位で上が 1 位）+ **登録キーワードのファインダビリティスコア**（黄）。ユーザー数 / セッション数 切替
- 「エンゲージの状況」セクション（全体 / 自社 切替）

### 05-b 最新の検索順位（自社・競合）

- ヘッダー操作: 「カスタムダッシュボードに追加」「ダウンロード」、チェック「競合の順位を表示」「過去の月間検索数推移」、「+グループに追加」、トレンドアイコンによるフィルタ（上昇 / 横ばい / 下降 など）
- 表: # / キーワード / 月間検索数 / PC（順位）: 増/減（ミニトレンド）/ 過去（2022-03-28）/ 最新（2022-04-27）/ URL
- 行例: seo 54,268 → 50+ → 50+ / コンバージョン 19,843 ↗ 50+ → 25 / オウンドメディア 16,226 ↘ 1 → 2 / コンテンツマーケティング 8,880 ↘ 25 → 50+ / キーワードツール 2,083 → 50+ → 50+
- 「50+」= 50 位圏外の表記（yoriai の「圏外」は 100 位）
