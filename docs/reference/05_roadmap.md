## Phase ごとの完了条件

- **Phase 1**: URL を入力すると、スコア + 総評 + セクション別の表（評価項目 / ステータス / 測定値・理由 / 改善提案）が出る。PSI の CWV が同じ画面に出る。llms.txt をダウンロードできる
- **Phase 2**: 開始 URL から 1,000 ページまでクロールし、10 カテゴリの課題数と前回比、課題一覧 CSV、LLM サマリーが出る。診断履歴から過去回を開ける
- **Phase 3**: 登録 KW が毎朝計測され、順位表（色分け・変化・LP・AI 概要）と日付比較ができる。AI Overviews の引用（自社 / 競合 / 未取得）が KW ごとに見え、グループ別に 5 区分の週次推移と出現率・引用率が描ける。GA4 連携で「AI 検索」チャネルの PV / CV / 流入ページ、AI 検索率、サービス別内訳が見える。サイトレポートで KPI の前期比とファインダビリティスコアが出る
- **Phase 4**: 登録プロンプトが定期実行され、平均ブランド言及率 / 平均ドメイン引用率、会社別・モデル別の時系列、ランキング、回答原文、競合比較表、未分類が見える。参考プロンプトから 50 本の関連プロンプトを生成してモニタリングに登録できる。プロンプトごとのファンアウトクエリと網羅率が見える。単発の LLM リサーチで ○× 行列を Excel 出力できる
- **Phase 5**: KW を入力するとページ診断（SERP 分析 / 課題分析 / コンテンツ分析の 3 タブ）と PDF が出る。AIO 頻出トピック表（出現割合・傾向・優先度）と不足トピックが KW ごとに見え、提案に反映される。キーワード調査でサジェスト + 検索数 + 意図が出る
- **Phase 6**: KW からの一発生成、企画書モード、チャット付きエディター、各種チェックが動く

## 先に決めておくこと

1. **SERP API の選定**（Phase 3 以降のほぼ全機能が依存）。日本ロケール、モバイル、100 件取得、AI Overviews の本文と参照 URL が取れること、Google AI モードの回答が取れること、料金
2. **検索ボリュームの取得方法**（Google Ads API を使うなら広告アカウントと開発者トークンの準備。無理なら有料 DB）
3. **LLM の使い分けと予算**（総評・提案は `claude-opus-5`、分類は `claude-haiku-4-5`、LLMO は各社 API）
4. **課金モデル**（yoriai 型のクレジット制にするか、User Insight 型の全部込みにするか。社内ツールなら上限管理のみで十分）

## 差別化の候補（両製品にないもの、または弱いもの）

- 課題ごとの「修正コードの提示」（title / description / JSON-LD / canonical の具体案を diff 形式で表示）
- 課題単位の「新規 / 継続 / 解消」トラッキングとタスク化（yoriai 比較表でタスク管理は各社 × or 弱い）
- アラート配信（順位急落、AI Overviews 引用喪失、LLMO 引用率低下、robots.txt で AI ボットがブロックされた）
- AI クローラ許可状況（robots.txt）と llms.txt の検証・監視
- LLMO の「未分類ドメイン Top10」からの競合自動提案
- ページ診断の提案を、そのまま AI ライティングの「追記」に流し込む導線（yoriai は別機能として分かれている）
- ミエルカ GEO が既に持つ プロンプト拡張 / クエリファンアウト / AIO 頻出トピック分析 は 2026 年時点で市場標準になりつつある。差別化は「ファンアウトクエリ → 不足トピック → 記事追記」を自動で一本につなぐ導線と、参照元・AI クローラ UA・ブランド別名の辞書をユーザー自身が拡張できる設計に置く
