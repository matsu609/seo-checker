### ポジショニング（p10）

横軸 = 費用（安 ↔ 高）、縦軸 = リテラシー（低 ↔ 高）、円の大きさ = サポートのきめ細かさ。yoriai は「安い × 低リテラシー向け」の空白地帯を狙う。既存製品のメリット: 国内製品はサポートが手厚い、海外製品は高度で細かい機能。デメリット: 国内製品は費用対でオーバースペック、海外製品は機能面でオーバースペック。

## 04. AI ライティング（p22〜25）

- Google Gemini を利用。「SEO 特化型の AI 自動記事作成」
- 記事作成のよくある悩み: 記事の書き方がわからない / 記事作成の時間がない / 競合調査に時間がかかる / どんな記事がいいかわからない
- 思想（p23〜24）: AI 文章が Google からスパム扱いされるという意見があるが、AI で文章を作成すること自体に問題はない。Google はユーザーに役立つ高品質なコンテンツを評価する。生成記事をそのまま使うことも可能だが、人間の手で独自性のある文章にリライトすると評価が高まる。AI ライティングはあくまで補助ツール。yoriai は「まず一発書きしてから修正する」（他ツールは細かくチェックしながら作るパターンが多い）
- 2 種類のライティング + エディター（p25、記事作成方法の選択モーダル）
  1. **AI ライティング**: キーワードを入力するだけで記事を自動生成。上位 10 位の競合サイトの分析内容を踏まえ、構成・見出し・本文を AI が生成。一発生成が特徴。「順位計測キーワードから選ぶ」チップ（計測済みは ✓ アイコン）。5 クレジット
  2. **企画書**: 書きたい記事の内容（0/1,000 文字）を入力すると AI が企画書を作成。企画書は自由に編集でき、その内容をもとに自動執筆。参考資料: 「Google 検索結果を参考にする」チェック / 「PDF 資料をアップロード」（5MB まで）/ 「参考情報をインポート」（セレクト）。10 クレジット
  3. **エディター**: エディターを開いて思い通りの記事を書く
- 記事一覧: タイトル / 企画書 / 作成日 / 公開。「+作成する」
- クレジット表から推定される付随機能: 再執筆（2）、記事チェック（3）、AI エディター（2）

## seo-checker1 に取り入れたい設計ポイント

1. **プロジェクト（= ドメイン）を最上位単位**にし、その下に サイト診断 / ページ診断 / 順位計測 / ライティング をぶら下げる情報設計。調査系（キーワード・競合・リアルタイム順位・被リンク）はプロジェクト横断
2. **上限管理を 2 系統**に分ける: サイト診断は URL 数、重い調査系はクレジット（機能ごとの単価表）。残高をサイドバー常時表示
3. **課題カテゴリー 10 種 + 前回比較バッジ**。差分が見えることで「結果が出ているかわからない」を解消
4. **順位表の視覚化ルール**（1〜5 / 6〜10 / 圏外、変化の赤緑、最新日を青字）
5. **ページ診断の「追加を推奨する箇所 / 追加するコンテンツの概要 / 提案理由」の 3 点セット**。提案を実行可能な粒度にする型
6. **AI 検索の 3 KPI**（AI 検索ボリューム総計 / 言及・引用回数 / 競合メディア数）+ **コンサルタント型サマリー**（強み / 課題 / 次の手）
7. **一発書き → 編集** の AI ライティング思想。企画書モードでは PDF / 検索結果を参考資料として渡せる
8. **LLM 生成の「サマリー文」を各機能のダッシュボード先頭に置く**（サイト診断・ページ診断・AI 検索すべてに共通）
