# 機能カタログ（3 製品横断）: どのようなものがあるか

凡例
- 出典: **UI** = User Insight（ユーザーローカル）、**YS** = yoriaiSEO（Cominka）、**MG** = ミエルカ GEO（Faber Company、[06_mieruca-geo.md](./06_mieruca-geo.md)）
- 外部依存: **なし** = 自前クロール・解析のみで可 / **SERP** = 検索結果取得 API / **KWDB** = キーワード DB（検索ボリューム・獲得 KW）/ **LLM** = 生成 AI API / **GA** = Google Analytics 4・Search Console 連携 / **BL** = 被リンク DB / **PSI** = PageSpeed Insights API（無料）
- 優先度: ★★★ = 早期に実装（依存が少なく価値が高い）、★★ = 中期、★ = 後期または有料 API 前提。詳細は [05_roadmap.md](./05_roadmap.md)

## 機能間の依存関係

- **SERP 取得基盤を 1 つ作ると 4 機能が乗る**: B1 順位計測 / B3 AI Overviews / A4 ページ診断の Top10 / D1 AI ライティングの上位 10 分析 は同じ SERP 取得結果を再利用できる。取得結果は生 JSON で保存しておく
- **ページ単位チェック関数群は共有**: A2 単一ページ診断 のチェックを、A1 サイト診断 が N ページ分呼び出し、さらにサイト横断チェック（重複・孤立・canonical 循環）を足す構造にする
- **LLM サマリー生成は共通部品**: サイト診断 / ページ診断 / AI 検索 / AIO レポート の「総評」は同じ「構造化データ → 日本語の総評 + 強み / 課題 / 次の手」テンプレートで作れる
- **C1〜C3 は有料 KW DB が前提**。無料で始めるなら Search Console（自社の獲得 KW と表示回数）と Google サジェストの組み合わせで C1 と C2 の自社分を代替できる
- **B8 ファンアウトクエリは B4 の LLM 呼び出しから追加コストなしで取れる**: Gemini の `webSearchQueries`、OpenAI の `web_search_call`、Claude の `server_tool_use` に検索クエリが含まれる。B4 を実装する時点で保存しておく
- **A5 は B3 の AIO 本文が前提**: 日次で本文を保存しておけば後から集計できる。トピック抽出は LLM バッチ
- **E8 は B1（順位）と B6（GA4）の合成**: 新しいデータ取得はなく、ファインダビリティスコアの計算と画面構成だけ

## 3 製品の違い（参考）

| 観点 | User Insight | yoriaiSEO | ミエルカ GEO |
|---|---|---|---|
| 母体 | アクセス解析（実流入データを持つ） | SEO ツール（クロール・SERP・LLM） | SEO ツール（ミエルカ SEO）の GEO 特化版。GA4 連携あり |
| LLMO の主対象 | 5 LLM のブランド言及・ドメイン引用（プロンプト単位） | Google AI Overviews の引用（サイト単位の総括 + KW 単位の AI 概要フラグ） | AIO（KW 単位の 5 区分・頻出トピック）+ マルチ LLM（単発リサーチ / 定点シェア / クエリファンアウト） |
| ページ診断 | URL 単位の AI 最適化スコア（AI フレンドリーさ） | KW 単位で SERP と比較（上位表示のための施策） | KW 単位の AIO 頻出トピックと自社の不足 |
| 生成 | 記事生成 + リライト・各種チェック・画像生成 | 記事生成（Gemini）+ 企画書 + エディター | LP には記事生成の記載なし（プロンプト拡張のみ） |
| 流入分析 | 生成 AI チャネル（PV / CV / ページ） | GA4 / GSC レポート（オプション） | AI 検索率（対総 / 対自然）、サービス別、ページ × 流入元 × キーイベント |
| 課金 | PV 量で月額（機能は全部込み） | 月額 + クレジット制 + URL 数上限 | LP からは不明（無料トライアルあり） |
